2. Tech Stack Research — Answer
Front-end tool: React
React is a JavaScript library used to build user interfaces. It allows developers to create reusable components such as buttons, navigation bars, forms, and different sections of a website.
Back-end tool: Node.js
Node.js allows developers to run JavaScript outside the browser. It can be used to create servers and APIs and to communicate with databases.
Homework — Answer
Front-End vs Back-End vs Full-Stack Development
Front-End Development
Front-end development focuses on the part of a website that users see and interact with. Front-end developers create layouts, buttons, menus, forms, images, and other visual elements.
Common front-end technologies include HTML, CSS, and JavaScript. Developers can also use libraries and frameworks such as React.
Back-End Development
Back-end development focuses on the server-side of a website. It handles data, business logic, authentication, APIs, and communication with databases.
Common back-end technologies include Node.js, Python, PHP, and Java. Common databases include MySQL and PostgreSQL.
Full-Stack Development
Full-stack development combines front-end and back-end development. A full-stack developer can work on both the user interface and the server-side of a web application.
A full-stack developer may use HTML, CSS, JavaScript, React, Node.js, and databases to create a complete web application.
