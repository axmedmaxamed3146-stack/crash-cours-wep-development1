The browser reads the URL.

Homework — Answer
The Journey of a URL
When I enter a URL into my browser, the browser first reads the URL and identifies the domain name. The browser then needs to find the IP address of the server where the website is hosted.
The browser uses DNS, which stands for Domain Name System, to translate the domain name into an IP address. DNS helps the browser find the correct server.
After the IP address is found, the browser connects to the web server. If the website uses HTTPS, the connection is secured. The browser then sends an HTTP request asking the server for the requested web page.
The web server receives the request and processes it. It then sends an HTTP response back to the browser. The response can contain HTML, CSS, JavaScript, images, and other resources.
The browser reads the HTML and creates the structure of the page. It then applies CSS to control the appearance and uses JavaScript when needed to add interaction.
Finally, the browser renders the page and displays it on the screen.
